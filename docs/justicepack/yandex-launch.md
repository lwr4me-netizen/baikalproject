# Маркетинговый пакет JusticePack: запуск через Яндекс Поиск

Аналог `docs/marketing-yandex.md`, ведётся отдельно: другая аудитория, другие запросы, другие минус-слова (см.
`docs/justicepack/market-validation.md` раздел 2 — почему выводы ArbitrPack нельзя переносить). Частотность и
стоимость клика НЕ выдуманы: доступа к Яндекс.Вордстату и рекламному кабинету в рамках этой сессии не было,
соответствующие поля помечены `UNKNOWN`. Владелец должен подставить реальные значения перед запуском (таблица
в конце файла).

**Реклама включается ТОЛЬКО после того, как владелец лично прошёл полный сценарий JusticePack на реальном
(не dev) окружении — загрузка → диагностика → тестовая оплата → обработка → скачивание → удаление — точно так
же, как это было условием для ArbitrPack (`docs/marketing-yandex.md`, раздел 12 ТЗ). Это `OWNER ACTION REQUIRED`.**

## 2. Минус-слова

`бесплатно скачать`, `образец искового заявления`, `юрист бесплатно`, `консультация юриста онлайн бесплатно`,
`вакансии`, `работа`, `суд онлайн смотреть`, `расписание судебных заседаний`, `решение суда скачать`,
`районный суд адрес`, `районный суд телефон`, `мировой судья участок номер`, `курсы`, `обучение`, `мой арбитр`
(другая система — трафик по этому запросу должен идти на ArbitrPack, не на JusticePack, если вообще идти на рекламу).

## 3. Этическое ограничение объявлений (специфично для JusticePack, отсутствовало в ArbitrPack в этой форме)

Аудитория JusticePack чаще состоит из людей без юридического опыта, часто в стрессовой ситуации (споры о
наследстве, увольнении, потребительские споры, иногда — процессуальные сроки "горят"). Объявления и посадочные
страницы обязаны:

- НЕ создавать искусственное чувство паники сверх уже существующей срочности пользователя;
- НЕ обещать ускорение самого судебного процесса или положительный исход — только техническую проверку файлов;
- Явно и без мелкого шрифта сообщать, что сервис не является юридической консультацией (уже реализовано в
  `apps/web/app/services/justicepack/page.tsx`, дисклеймер).

## 4. 3 варианта заголовка

1. Документы для суда не загружаются? Проверим за 2 минуты
2. Ошибка при подаче в ГАС «Правосудие» — найдём техническую причину
3. Требования к файлам для суда общей юрисдикции — проверка онлайн

## 5. Варианты объявлений (заголовок + текст)

1. **Заголовок:** Ошибка загрузки документов в суд?
   **Текст:** Проверим PDF и сканы за 2 минуты: формат, размер, защита паролем. Бесплатная диагностика, оплата только за готовый архив. Не юридическая консультация.

2. **Заголовок:** Файл не проходит в ГАС «Правосудие»
   **Текст:** Найдём техническую причину: пароль на файле, повреждённый PDF, превышение размера. Исправим что можно автоматически.

3. **Заголовок:** Проверка документов перед подачей в суд общей юрисдикции
   **Текст:** Технические ошибки в файлах — частая причина отказа загрузки. Диагностика бесплатна, готовый архив — по фиксированной цене.

4. **Заголовок:** Требования к файлам для районного/мирового суда
   **Текст:** PDF, JPG, PNG — проверим формат и размер по официальным техническим требованиям. Результат за минуты.

## 6. 3 ценностных предложения

1. **Понятность**: объясняем на простом языке, что не так с файлом, без юридического жаргона.
2. **Прозрачность**: список всех найденных проблем показывается бесплатно, до оплаты.
3. **Честность**: сервис прямо говорит, чего не может — не подписывает документы и не гарантирует принятие судом.

## 7. Структура UTM

```
utm_source=yandex
utm_medium=cpc
utm_campaign=justicepack_{ad_group_theme}   # напр. justicepack_error-upload, justicepack_requirements, justicepack_urgent
utm_content={ad_variant_id}
utm_term={keyword}
```

Пример: `https://baikalproject.pro/services/justicepack?utm_source=yandex&utm_medium=cpc&utm_campaign=justicepack_urgent&utm_content=ad1`

Префикс `justicepack_` в `utm_campaign` — обязателен, иначе атрибуция кампаний двух продуктов будет неотличима
в отчётах Яндекс.Директ даже при том, что backend разделяет их по `product_code` (UTM и `product_code` — два
независимых механизма разделения, оба нужны).

## 8. События конверсии

Те же имена событий, что у ArbitrPack (единый список `VALID_EVENTS`, см. `app/services/analytics.py`) — но
КАЖДОЕ теперь несёт `product_code=JUSTICEPACK`, поэтому в Яндекс.Метрике (если будет подключена) цели необходимо
считать отдельно от ArbitrPack:

1. `upload_started` / `upload_completed` — файлы загружены (микро-конверсия).
2. `diagnostics_free_result_shown` — увидел бесплатный результат (микро-конверсия).
3. `checkout_started` — начал оплату (макро-конверсия).
4. `payment_succeeded` — оплатил (макро-конверсия, ценность = `amount`).

Источник правды для этих событий в разрезе JusticePack — `GET /api/admin/metrics?product_code=JUSTICEPACK`.

## 9. Минимальный сценарий A/B-теста

- **Гипотеза**: заголовок с бытовой формулировкой ("документы для суда", без термина "ГАС Правосудие") даёт более
  высокий CTR у аудитории, впервые подающей документы, чем заголовок с официальным названием системы.
- **Вариант A**: заголовок №2 (с официальным названием "ГАС «Правосудие»").
- **Вариант B**: заголовок №1 (бытовая формулировка "Документы для суда").
- **Метрика решения**: CTR за первые 200–500 показов на группу, затем конверсия `checkout_started` за первые
  20 переходов на группу.
- **Длительность**: до ~100 кликов на вариант или 7 дней, что раньше.

## 10. Правила остановки неэффективной рекламы

1. Потрачено ≥ 3 × ожидаемая цена одной оплаты (399 ₽ × 3 = 1197 ₽, если тариф не изменён владельцем) без единой
   оплаты — *после* первых 50 кликов.
2. CTR группы < 0.5% после 1000 показов.
3. Конверсия `upload_completed → payment_succeeded` < 1% после 30 полных бесплатных диагностик JusticePack —
   сигнал проблемы в продукте/цене для ЭТОЙ аудитории (нельзя считать по объединённым с ArbitrPack данным).
4. Допустимый CAC (см. `docs/justicepack/market-validation.md`) превышен за скользящее окно 3 дня.
5. Дополнительно для JusticePack: любая жалоба/сигнал, что объявление воспринимается как введение в заблуждение
   относительно гарантий приёма судом или срочности — кампания останавливается немедленно вне зависимости от
   финансовых показателей (раздел 3 выше).
