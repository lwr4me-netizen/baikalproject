# Политика конфиденциальности BAIKALPROJECT (черновик — OWNER ACTION REQUIRED перед публикацией)

**Статус документа:** черновик для запуска MVP, распространяется на оба аппарата платформы — ArbitrPack («Мой
Арбитр») и JusticePack (ГАС «Правосудие»); технические меры обработки данных у них одинаковые (один backend, одна
БД, один порядок хранения/удаления — см. раздел 4), различается только конечная система подачи, для которой
готовятся документы. Требует проверки юристом на соответствие Федеральному закону № 152-ФЗ «О персональных данных»
и подстановки реальных реквизитов оператора персональных данных перед публикацией на реальном домене (см.
`docs/requirements-sources.md`, правило R-10 — помечено `UNVERIFIED`).

технический вопрос.

## 2. Какие данные обрабатываются

- Файлы, которые пользователь загружает для технической проверки (могут содержать ФИО, адреса, номера дел и другие
  персональные данные, содержащиеся в документах пользователя).
- Технические метаданные: IP-адрес (хранится только в виде необратимого хэша, см. `ConsentRecord.ip_hash`), время
  загрузки, идентификатор сессии (случайный UUID, без привязки к личности до тех пор, пока пользователь сам не
  укажет её в документе).
- Данные об оплате: обрабатываются платёжным провайдером (ЮKassa); ни ArbitrPack, ни JusticePack (единый backend
  BAIKALPROJECT) не хранят номера банковских карт.

## 3. Цели обработки

Исключительно техническая подготовка и проверка загруженных документов по запросу пользователя: диагностика,
формирование отчёта, безопасные автоматические исправления (удаление метаданных/EXIF), сборка итогового архива.

## 4. Срок хранения

Пользователь выбирает срок автоматического удаления при загрузке: 24 часа, 3 дня или 7 дней. По истечении срока
файлы удаляются автоматически (см. `scripts/ttl_cleanup.py`). Пользователь может запросить немедленное удаление в
любой момент через кнопку «Удалить мои файлы сейчас» на экране результата.

## 5. Передача третьим лицам

- Платёжные данные передаются платёжному провайдеру (ЮKassa) для обработки оплаты — в объёме, необходимом для
  проведения платежа.
- Иным третьим лицам содержимое документов не передаётся. Сторонние аналитические трекеры (Google Analytics и т.п.),
  получающие содержимое или имена файлов, не используются (см. `docs/analytics.md`).

## 6. Права пользователя

- Запросить немедленное удаление своих данных.
- Узнать, какие данные хранятся (в рамках MVP — через обращение к оператору, отдельный API самообслуживания не
  реализован).

## 7. Хранение и защита

Файлы хранятся в закрытом объектном хранилище (S3-совместимом, MinIO при самостоятельном развёртывании) без
публичного доступа. Доступ к результатам — только по временной подписанной ссылке с ограниченным сроком действия.
Подробности технических мер — в `SECURITY.md` и `docs/threat-model.md`.
